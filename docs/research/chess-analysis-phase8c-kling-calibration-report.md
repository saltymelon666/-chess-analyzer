## 校准方法

每张原书图盘保留20个棋盘边界候选及其棋子模型置信度。排序不再只取模型最高置信度，而是同时考虑：

1. 第一批已确认图盘给出的同版式棋盘边界位置；
2. 候选边界相对图片宽高的几何距离；
3. 64格棋子识别的平均和最低置信度。

校准只学习同一本书的印刷版式边界，不学习残局结论、走法、胜负或棋理文本。

## 校准结果

- 第一批16题逐题留一校验：16/16恢复为裁决后的棋子摆放。
- 185张图片中183张拥有可供校准的边界候选。
- 校准后43张同时满足双王完整且至少一个行棋方棋盘合法。
- 排除第一批16张后，12张满足第二批门禁：平均格置信度不低于0.90、不同摆放候选的选择分差不低于0.02、双王完整且棋盘合法。
